# 任务卡模板

每个研发任务都应复制本模板到 `docs/tasks/TASK-<MODULE>-<ID>.md`，确保任务可执行、可验证、可审查。

## 任务 ID

`TASK-<MODULE>-<NUMBER>`

示例：

- `TASK-RECIPE-001`
- `TASK-PLAN-002`
- `TASK-BASKET-003`
