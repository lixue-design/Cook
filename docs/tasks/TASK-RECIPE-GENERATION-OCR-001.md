# TASK-RECIPE-GENERATION-OCR-001 图片 OCR 生成菜谱

## 目标

将文字菜谱截图通过腾讯云通用印刷体 OCR 提取文字，再复用个人版环境中的 `hy3` 生成可编辑菜谱草稿。

## 范围

- 图片入口选择一张压缩图片后直接发起识别，不再要求用户补充菜名或食材说明。
- 图片仅临时上传至个人版 AI 环境；OCR 和草稿生成结束后立即删除。
- OCR 文本不返回客户端、不写入业务数据库、不记录完整日志。
- 识别失败时提示更换清晰截图或手动填写。
- 草稿必须进入既有编辑页，由用户确认保存。

## 不包含

- 成品菜照片、手写菜谱、非文字图片的识别。
- 直接创建正式菜谱。
- 保留原始图片或 OCR 全文。

## 验收

- 文字菜谱截图可生成编辑草稿。
- 临时图片在成功、OCR 失败和模型失败后均尝试删除。
- 已有文字生成、手动填写和菜谱保存流程不受影响。
- 不将 OCR 凭证或云函数环境变量发送到小程序端。
