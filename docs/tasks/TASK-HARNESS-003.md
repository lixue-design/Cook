# TASK-HARNESS-003 全量任务队列与自动执行规则

## 任务 ID

`TASK-HARNESS-003`

## 背景

`docs/tasks/README.md` 原本只列出第一批任务卡，无法支撑 Agent 自动持续执行到 MVP 完整闭环。需要把任务队列、状态标记、自动取下一个任务的规则和完成定义固化下来。

## 目标

建立全量 MVP 任务队列和自动执行规则，让 Codex 可以按顺序推进任务，直到完成 MVP 提测和提审准备。

## 范围

### 包含

- 更新任务索引为全量 MVP 队列。
- 定义任务状态：`Todo`、`Doing`、`Done`、`Blocked`、`Deferred`。
- 明确自动选择下一个任务的规则。
- 明确 MVP 整体完成定义。
- 补齐缺失任务卡的索引入口。

### 不包含

- 不直接实现业务代码。
- 不替代每张任务卡的验收标准。
- 不把 AI、月计划、运营后台加入 MVP 主链路。

## 实现要求

- 队列必须覆盖登录、菜谱、计划、菜篮、合规、硬化、验收和发布准备。
- 每个队列项必须指向具体任务卡。
- 自动执行规则必须能处理阻塞任务。
- 完成定义必须引用 MVP 验收清单和提审前冒烟路径。
