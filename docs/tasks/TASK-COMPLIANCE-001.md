# TASK-COMPLIANCE-001 我的页、协议、隐私与注销入口

## 任务 ID

`TASK-COMPLIANCE-001`

## 背景

小程序提审需要用户服务协议、隐私政策、账号注销入口等基础合规能力。当前 `pages/profile/index` 只有占位内容，协议页和注销页尚未完整注册。

## 目标

补齐我的页、协议页、隐私政策页和账号注销说明/申请入口，满足 MVP 提审基础要求。

## 范围

### 包含

- 我的页展示登录用户信息。
- 用户服务协议入口和页面。
- 隐私政策入口和页面。
- 账号注销说明页。
- 提交注销申请或形成待处理记录。
- 退出登录入口。
- 页面加载态、空态、失败态和未登录态。

### 不包含

- 不做 15 个工作日自动清理全量数据。
- 不做后台运营处理台。
- 不做复杂协议版本升级弹窗，除非 PM 确认。

- MVP 范围：`docs/mvp-scope-and-implementation-breakdown.md`

- 依赖任务：`TASK-AUTH-001`

## 实现要求

- 协议和隐私正文可先用静态内容，但必须有明确版本。
- 注销申请需写入服务端或形成可追踪记录。
- 未登录时我的页展示登录引导。
- 退出登录后回到未登录状态。
- 不提交真实用户隐私数据或生产配置。

## 前端设计保护

当前 profile 很薄，可新增页面和样式；不得影响已完成 Tab、弹窗和核心页面设计。

- 是否改 WXML：是，限 profile/协议/注销页面
- 是否改 WXSS：是，限 profile/协议/注销页面
- 是否改组件结构：可新增合规页面，不改核心组件
- 是否保持现有字段契约：是
- 是否优先通过 `services/` 或数据映射接入：是
- 视觉回归范围：
  - 页面：我的页、协议页、隐私政策页、注销说明页
  - 弹窗：退出登录确认、注销申请确认
  - 手势：不涉及
  - 空态/加载态/失败态：未登录、提交失败、协议加载失败

## API/数据变更

- 可新增：
  - 协议正文/版本 action 或静态页面。
  - 注销申请 action/API。
  - `account_cancel_requests` 或等价数据结构。

## 验收标准

- [ ] 我的页展示当前登录用户信息。
- [ ] 可查看用户服务协议。
- [ ] 可查看隐私政策。
- [ ] 可进入账号注销说明页。
- [ ] 可提交注销申请或形成待处理记录。
- [ ] 可退出登录。
- [ ] 未登录态展示合理。

## 测试要求

- [ ] 单元测试：注销申请参数校验，如有。
- [ ] 接口测试：协议读取、注销申请。
- [ ] 页面冒烟：我的页 -> 协议 -> 隐私 -> 注销 -> 退出登录。
- [ ] 回归范围：自定义 Tab、核心页面未登录跳转。

## 风险

- 协议和隐私文案需要 PM/法务确认。
- 注销真实清理流程可后置，但入口和申请记录必须明确。
