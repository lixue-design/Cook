# TASK-ACCOUNT-CANCEL-EXECUTE-001

## 任务 ID

`TASK-ACCOUNT-CANCEL-EXECUTE-001`

## 背景

用户已确认采用自助注销：不需要运营者逐条处理，用户确认后进入 7 天可撤回期，到期由受保护的服务端定时任务自动删除数据。仍需保留最小完成记录、失败重试和真实环境演练，避免不可逆删除误触发。

## 目标

实现并验证自助注销闭环：用户创建/撤回申请，定时任务在到期后删除数据和封面文件，出现临时故障时自动重试。

## 当前状态

`Ready for environment validation`

## 待完成的环境配置

- 在云函数运行时配置内部定时令牌，并用同一令牌建立每日定时触发。
- 将迁移应用到体验环境后，使用专用测试账号完成一次真实删除演练。
- 在下一次发布前核对协议版本提示与隐私政策配置。

## 范围

### 包含

- 用户创建、查看、撤回注销申请。
- 7 天可撤回期和预计删除时间。
- 内部定时任务执行封面清理与账号数据删除。
- 幂等执行和失败重试。
- 删除完成后的最小无身份完成记录。

### 不包含

- 客户端直接触发最终删除。
- 人工逐条审核普通注销申请。
- 恢复已完成注销的账号或内容。
- 删除法律法规要求保留的脱敏日志。

## 实现要求

- 最终删除只能由带内部令牌的云开发定时任务触发。
- 执行任务必须幂等、可重试且不记录原始用户数据到完成记录。
- 删除范围覆盖用户资料、自建菜谱、计划、菜篮、分类、生成草稿和封面文件。
- 不得删除必须保留的合规审计记录；保留记录必须脱敏且不可关联 OpenID。

## Full PRD 限制

- Provider 策略：不涉及 AI；不触发生成 provider。
- 前端样式保护：只扩展现有注销页的状态文案和撤回按钮，不改变导航、自定义 Tab 或安全区布局。
- 数据事实来源：注销处理任务状态和审计日志是处理事实源。
- 快照规则：删除/匿名化不得破坏需依法保留的脱敏审计证据。
- 用户隔离：处理范围必须按 owner 精确限定。
- 不可做事项：不在合规门禁缺失时实现真实执行，不允许客户端执行最终删除。
