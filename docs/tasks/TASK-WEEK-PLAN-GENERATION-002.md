# TASK-WEEK-PLAN-GENERATION-002：修正周计划餐次与排序规则

## 目标

让自动周计划的餐次分类、同餐顺序和内置早餐内容符合真实用餐习惯。

## 本次范围

- 普通含鸡蛋菜品（如“西红柿炒鸡蛋”）不因“鸡蛋”被归类为早餐；同样不把玉米、牛奶等食材词单独视为早餐，并排除带正餐烹饪语义的菜谱。
- 组合午餐、晚餐的主食固定写入为该餐第一条。
- 无早餐菜谱时，内置早餐以独立食材条目写入：
  - 玉米、鸡蛋、牛奶；
  - 燕麦、牛奶；
  - 吐司、鸡蛋；
  - 豆浆、面包。
- 回填已有菜谱的系统标签，但不改写已生成的历史计划和菜篮快照。
- 清空周计划使用一次原子删除，不保留会触发重新生成冲突的空计划记录。

## 实现边界

- 修改服务端系统标签构建与周计划生成器。
- 修改数据库迁移并部署到体验环境。
- 不新增用户偏好项、不调整计划页面布局。

## 验收

- “西红柿炒鸡蛋”系统标签不含 `breakfast`。
- 自动生成的组合午餐、晚餐按主食、荤菜、素菜顺序展示。
- 内置早餐“燕麦牛奶”显示为燕麦、牛奶两条；“玉米鸡蛋牛奶”显示为玉米、鸡蛋、牛奶三条。
- 已生成历史计划与菜篮内容不被回填操作修改。

## 验证

- 周计划生成器单元测试。
- 数据库迁移结构测试；有独立测试数据库时，额外运行迁移集成测试。
- 体验环境就绪检查和一次实际生成冒烟验证。
