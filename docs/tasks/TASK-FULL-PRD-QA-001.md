# TASK-FULL-PRD-QA-001 Full PRD 验收清单

## 任务 ID

`TASK-FULL-PRD-QA-001`

## 背景

Full PRD 阶段新增能力较多，覆盖 AI、月计划、运营和注销自动化。需要在代码实现前建立全量 PRD 验收清单，避免把单测通过误认为真实功能完成。

## 目标

建立 Full PRD parity checklist，用于后续每个阶段提测、提审和发布前逐项验收。

## 范围

### 包含

- 规则优先的菜谱生成验收项。
- AI 菜品图库和运营验收项。
- 日计划增强和月计划验收项。
- 注销自动化和协议版本验收项。
- 真实环境、成本、安全和回滚门禁。

### 不包含

- 不实现测试脚本。
- 不执行人工验收。
