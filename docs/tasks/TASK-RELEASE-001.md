# TASK-RELEASE-001 小程序提审前发布清单与运行手册

## 任务 ID

`TASK-RELEASE-001`

## 背景

MVP 功能完成后，还需要确认发布配置、环境变量、数据库迁移、Cloud Function、协议文案、回滚方案和提审风险。没有发布清单时，Agent 即使完成代码任务，也无法判断是否真正可提审。

## 目标

形成小程序提审前发布清单和最小运行手册，明确上线前检查、发布步骤、回滚和已知风险。

## 范围

### 包含

- 小程序提审前配置检查。
- 服务端/Cloud Function 发布前检查。
- 数据库 migration 和回滚检查。
- 环境变量和密钥检查。
- 协议、隐私、注销入口检查。
- MVP 冒烟和验收清单引用。
- 回滚或降级策略。

### 不包含

- 不提交小程序审核。
- 不操作生产环境或真实用户数据。
- 不自动删除用户数据。
- 不开通微信、CloudBase、对象存储等外部权限。

## 相关上下文

- 本地验证：`docs/harness/local-development-and-verification.md`
- MVP 验收：`docs/checklists/mvp-acceptance.md`
- PR checklist：`docs/reviews/pr-review-checklist.md`
- 工程方案：`docs/engineering-framework-and-team-plan.md`
- 依赖任务：`TASK-QA-MVP-001`

## 实现要求

- 清单必须区分本地、测试、生产环境。
- 明确哪些配置不能提交到代码。
- 明确 migration 执行和回滚验证方式。
- 明确提审前必须人工确认的项目，如协议文案和微信类目/隐私声明。
- 明确无法自动化的外部依赖。

## 前端设计保护

不涉及页面改动。

- 是否改 WXML：不涉及
- 是否改 WXSS：不涉及
- 是否改组件结构：不涉及
- 是否保持现有字段契约：不涉及
- 是否优先通过 `services/` 或数据映射接入：不涉及
- 视觉回归范围：
  - 页面：不涉及
  - 弹窗：不涉及
  - 手势：不涉及
  - 空态/加载态/失败态：不涉及

## API/数据变更

不涉及。

## 验收标准

- [x] 发布清单覆盖小程序、服务端、数据库、配置和合规。
- [x] 明确禁止提交密钥、AppSecret、生产连接串。
- [x] 明确 migration 和回滚检查方式。
- [x] 明确提审前人工确认项。
- [x] 明确发布失败或关键接口不可用时的降级/回滚策略。

## 测试要求

- [x] 文档检查：清单引用 MVP 验收和本地验证文档。
- [x] 文档检查：发布步骤不包含真实密钥。
- [x] 回归范围：不涉及业务代码运行；另执行服务端构建确认文档未掩盖编译回归。

## 完成记录

- 发布手册：`docs/checklists/TASK-RELEASE-001-release-runbook.md`
- 自动检查：`npm run test:release-docs`
- 构建检查：`npm --prefix server run build`
- 当前发布结论仍为 `Blocked`：真实 remote 配置、数据库演练、微信/CloudBase 连续冒烟及
  产品/法务确认必须由外部负责人完成；任务完成仅代表运行手册和门禁已建立。

## 风险

- 提审策略、法务文案、生产权限和外部平台配置必须由人类负责人最终确认。
