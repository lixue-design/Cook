# TASK-BASKET-DETAIL-001 菜谱详情直加菜篮真实化

## 背景

横向硬化回归发现 `pages/recipe-detail/index` 的“加菜篮”仍调用
`utils/shopping-list.js` 写入 `app.globalData`。菜篮页已经改为按周读取真实 API，
因此按钮提示成功但真实菜篮不可见，破坏 MVP 明确要求的详情页直加菜篮闭环。

## 目标

在不改变详情页视觉的前提下，让当前菜谱食材通过服务端可信身份写入本周菜篮，
刷新后可见，并保留计划同步产生的条目。

## 范围

- 新增 owner-scoped 的菜谱直加菜篮 action/RPC。
- 只从服务端当前用户菜谱读取食材，不信任客户端食材或 ownerId。
- 写入来源引用；同一菜谱重复添加应幂等或返回可解释结果。
- 详情页只改 JS service 调用，不改 WXML/WXSS。
- 接口失败不得提示成功。

## 不包含

- 不做单位换算。
- 不改变周计划同步规则。
- 不新增分享或跨用户菜谱能力。

## 验收标准

- [ ] 详情页点击“加菜篮”后，本周真实菜篮刷新可见。
- [ ] 不信任客户端传入的食材、用户 ID 或 owner ID。
- [ ] 计划同步不删除详情直加的条目。
- [ ] 重复点击不会无限创建完全相同的来源项。
- [ ] 接口和 service 映射有自动测试。
- [ ] WXML/WXSS 未修改。
