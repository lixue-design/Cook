# 用户资料规则

## 首次登录初始化

- 服务端在首次成功登录时初始化资料；后续登录不覆盖用户主动编辑的资料。
- 登录不请求微信昵称或头像，资料仅使用系统默认值或用户在“编辑资料”页主动修改的内容。
- 系统内置 6 个预置头像，首次初始化时随机选择一个并持久化保存。
- 默认用户名格式为 `食光旅人 XXXX`。`XXXX` 为 4 位大写英文与数字组成的随机码，排除 `O`、`0`、`I`、`1`。
- 默认码由服务端生成并唯一约束；出现冲突时重新生成，确保不同用户的默认用户名不同。
- 旧用户保留已有用户名和头像；任一字段为空时只补齐缺失字段。

## 编辑资料

- 用户可在“编辑资料”页修改头像和用户名。
- 系统默认资料只用于初始化，不在后续登录时重新随机分配。
