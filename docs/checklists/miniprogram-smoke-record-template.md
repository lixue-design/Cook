# Mini Program Smoke Record Template

用于记录小程序页面或主路径的手动冒烟结果。不要记录真实用户手机号、openid、unionid、token、密钥、生产连接串或未脱敏截图。

## 使用时机

- 任务改动了小程序页面、组件、`services/` 数据来源或页面数据映射。
- 任务涉及登录态、空态、失败态、上传、删除、覆盖、同步或拖拽/滑动等关键交互。
- 微信开发者工具、Cloud Function 或真实后端不可用时，也必须复制本模板记录替代检查。
- `TASK-QA-MVP-001` 执行最终 MVP 验收时，可用本模板逐页记录结果。

## 状态覆盖

- [ ] 加载态符合现有设计。
- [ ] 空态明确且不遮挡主要操作。
- [ ] 失败态有可理解提示或重试入口。
- [ ] 未登录态能引导登录或阻止写操作。
- [ ] 删除、覆盖、退出等危险操作有确认。
- [ ] 保存失败不丢关键输入。
- [ ] 视觉和交互保留现有小程序设计基线。
- [ ] 自定义 Tab、半屏弹窗、安全区适配未回归。
- [ ] 关键手势未回归：滑动删除、长按拖拽、周切换、弹窗开合。
