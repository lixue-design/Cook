# Full PRD 验收清单

本文用于 MVP 之后的全量 PRD 能力验收。复选框只有在对应功能真实实现、自动验证和人工/真实环境验收完成后才能勾选。

## 1. 规则优先的菜谱生成

- [ ] 链接生成入口可用。
- [ ] 链接格式错误时保留用户输入并提示。
- [ ] 非菜谱链接不会生成错误菜谱。
- [ ] 图片生成入口可用。
- [ ] 图片格式和大小前后端均校验。
- [ ] 首版未接 AI 时，图片入口不伪装视觉识别；信息不足时提示用户补充。
- [ ] 文字生成入口可用。
- [ ] 空文字输入会被拦截。
- [ ] 三种生成结果均进入可编辑草稿，不直接保存正式菜谱。
- [ ] 不配置 AI 模型时，三种入口均可通过 `provider=rules` 完成可控流程。
- [ ] 生成草稿可保存为正式菜谱并进入详情。
- [ ] provider 输出非法时服务端拦截。
- [ ] 失败态有稳定错误 code 和 requestId。
- [ ] 小程序端不包含模型密钥。

## 2. AI 菜品图库

- [ ] 菜名停止输入后可触发图库匹配。
- [ ] 同义词可命中同一标准菜品图。
- [ ] 首版未命中图库时返回占位或运营待补状态。
- [ ] 图片生成失败不阻塞菜谱保存。
- [ ] 用户手动上传图片优先级最高。
- [ ] 运营可查看图库资源。
- [ ] 运营可替换、下线或重新生成图片。
- [ ] 运营可维护同义词映射。
- [ ] 图库变更有审计记录。
- [ ] 生成成本和频率限制生效。
- [ ] 图片内容安全审核通过。

## 3. 日计划增强

- [ ] 用户可设置是否吃早餐。
- [ ] 用户可设置早餐、午餐、晚餐偏好。
- [ ] 用户可设置忌口、常用主食、用餐人数和可接受耗时。
- [ ] 可查看历史日期日计划。
- [ ] 可将历史日计划复刻到目标日期。
- [ ] 目标日期已有计划时有覆盖/合并确认。
- [ ] 复刻后计划项保留快照。
- [ ] 可选择部分菜品同步菜篮。
- [ ] 选择性同步保留手动菜篮项。
- [ ] 同步失败不清空现有菜篮。

## 4. 月计划

- [ ] 周/月计划生成会读取用户习惯。
- [ ] 生成结果体现早餐、午餐、晚餐差异。
- [ ] 正餐搭配优先覆盖主食、蛋白质和蔬菜。
- [ ] 日计划是唯一事实，周/月计划从日级事实聚合。
- [ ] 可查看指定月份月历。
- [ ] 月历展示每日早餐、午餐、晚餐概览。
- [ ] 点击日期可进入对应日计划。
- [ ] 可将某周计划填充到月内空白周。
- [ ] 可批量清空整月或指定周次并二次确认。
- [ ] 可将某周或某月计划复用到目标月份。
- [ ] 可在月度范围内全局替换指定菜品。
- [ ] 月度统计展示总菜品数、不重复菜品数、高频食材和空缺日期。
- [ ] 可保存月度模板。
- [ ] 可将月度模板应用到另一个月份。
- [ ] 批量操作失败时有成功/失败明细。

## 5. 注销自动化与协议版本

- [ ] 用户可查看当前注销申请状态。
- [ ] 注销申请有状态机和审计记录。
- [ ] 处理 SLA 和到期提醒生效。
- [ ] 管理员可执行 dry-run 并查看处理清单。
- [ ] 正式执行需要管理员鉴权和二次确认。
- [ ] 注销处理任务幂等。
- [ ] 用户资料、自建菜谱、计划、菜篮按规则删除或匿名化。
- [ ] 法规要求保留的日志已脱敏。
- [ ] 注销完成后用户无法访问原账号数据。
- [ ] 协议版本更新后可触发重新确认。

## 6. 安全、成本与发布

- [ ] 所有新增写接口需要登录态或管理员鉴权。
- [ ] 所有用户数据按 owner 隔离。
- [ ] 生成输入和输出经过 schema 与内容安全检查。
- [ ] 首版无需 AI 模型即可完成规则生成主流程。
- [ ] 后续如启用 AI provider，必须有成本上限、频率限制和熔断。
- [ ] 管理员接口不可被普通用户访问。
- [ ] 数据库 migration 有 up/down 或等价验证。
- [ ] 小程序页面覆盖加载态、空态、失败态和未登录态。
- [ ] 真实 CloudBase、微信登录、存储桶和模型 provider 已联调。
- [ ] 全链路真机冒烟通过。
- [ ] 发布清单包含回滚、降级和密钥检查。

## 7. Full PRD 冒烟路径

```text
登录
-> 设置吃早餐/三餐偏好/忌口/主食
-> 链接规则生成菜谱草稿
-> 图片规则生成菜谱草稿
-> 文字规则生成菜谱草稿
-> 保存并编辑菜谱
-> 图库匹配/手动替换封面
-> 生成周计划
-> 复刻历史日计划
-> 选择部分菜品同步菜篮
-> 查看月计划并确认日/周/月联动
-> 批量填充/替换月计划
-> 查看月度统计
-> 保存并应用月度模板
-> 提交注销申请
-> 管理端 dry-run 与处理
-> 协议版本更新后重新确认
```
