## 范围

- 所有实现均有关联任务卡；新增详情直加菜篮和 RPC 加固任务已补入队列。
- 未加入 AI 生成、月计划、运营后台、社交或复杂单位换算。
- 核心 WXML/WXSS 仅做状态小修；未重写自定义 Tab、半屏弹窗或手势结构。

## 业务规则

- 计划写入保存快照；删除/编辑菜谱不污染历史计划。
- 菜篮只合并同名同单位可解析数字项；manual 项不被计划同步删除。
- 详情直加菜篮从服务端 owner 菜谱取食材，客户端不能伪造。

## 接口与数据

- 新 action 均有可信身份、参数校验、稳定错误码和用户可读 message。
- 用户表、计划、菜篮、注销申请均有 owner 隔离。
- 迁移 0001–0014 均有 down 和静态契约；真实测试库验证阻塞。
- 安全扫描未发现硬编码密钥、token 或数据库连接串。

## 前端体验

- 核心页面具备 loading / empty / error / unauthenticated 处理。
- 保存失败保留输入；删除、覆盖、退出和注销有确认。
- service 层承担真实 API 映射。
- 视觉、手势和安全区仍需微信开发者工具人工验收。

- 服务端完整测试 80 项中 76 通过；1 项缺测试数据库、3 项受端口沙箱限制。
- 模块 spec、API 状态、迁移记录、诊断指南和任务状态均有同步。
