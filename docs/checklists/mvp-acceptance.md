# MVP 验收清单

本文作为 MVP 提测、提审、上线前的统一验收清单。

2026-07-31 自动化验收、替代证据和真实环境阻塞逐项记录见
[`TASK-QA-MVP-001-acceptance-record.md`](TASK-QA-MVP-001-acceptance-record.md)。
本清单中的复选框仅在真实环境/人工验收完成后勾选，避免把静态检查冒充真机通过。

## 1. 登录与合规

- [ ] 首次进入核心功能时引导登录。
- [ ] 微信快捷登录成功后可进入主功能。
- [ ] 登录前展示协议勾选。
- [ ] 用户服务协议可查看。
- [ ] 隐私政策可查看。
- [ ] 我的页展示用户信息。
- [ ] 可退出登录。
- [ ] 可进入账号注销说明页。
- [ ] 可提交注销申请或形成待处理记录。

## 2. 菜谱

- [ ] 菜谱列表可加载。
- [ ] 分类可新增。
- [ ] 分类可编辑。
- [ ] 分类可删除，菜谱归入未分类。
- [ ] 分类可排序或至少有稳定排序。
- [ ] 可新建菜谱。
- [ ] 可上传或选择封面图。
- [ ] 可填写主料、辅料、调料。
- [ ] 可添加、删除、编辑步骤。
- [ ] 可编辑已有菜谱。
- [ ] 可删除菜谱。
- [ ] 删除菜谱后列表不再展示。
- [ ] 删除菜谱后历史计划快照仍可展示。

## 3. 计划

- [ ] 可查看日计划。
- [ ] 日计划固定展示早餐、午餐、晚餐。
- [ ] 可添加菜谱到指定餐段。
- [ ] 可移除餐段菜谱。
- [ ] 点击计划中的菜谱可进入详情。
- [ ] 可查看周计划。
- [ ] 可生成本周计划。
- [ ] 已有计划时生成会提示覆盖确认。
- [ ] 菜谱不足时有 warning，不导致页面崩溃。
- [ ] 日计划修改后周计划同步展示。

## 4. 菜篮

- [ ] 可查看当前周菜篮。
- [ ] 可从周计划同步菜篮。
- [ ] 同名同单位数字食材自动求和。
- [ ] 同名不同单位食材分行展示。
- [ ] 不可解析用量保留原始文本。
- [ ] 可勾选/取消勾选食材。
- [ ] 可手动新增食材。
- [ ] 可删除食材。
- [ ] 再次同步不会删除手动新增项。

## 5. 错误态与空态

- [ ] 菜谱列表空态明确。
- [ ] 日计划空态明确。
- [ ] 周计划空态明确。
- [ ] 菜篮空态明确。
- [ ] 网络失败有提示。
- [ ] 保存失败不丢表单内容。
- [ ] 图片上传失败可重试或无图保存。

## 6. 数据与安全

- [ ] 所有用户数据按用户隔离。
- [ ] 写接口需要登录态。
- [ ] 数据库不保存明文密钥。
- [ ] 小程序端不包含 AppSecret。
- [ ] 删除用户内容符合软删除或明确策略。
- [ ] 计划和菜篮使用快照。

## 7. 提审前冒烟路径

```text
登录
-> 新建菜谱
-> 查看详情
-> 编辑菜谱
-> 生成周计划
-> 添加/移除某日餐段菜谱
-> 同步菜篮
-> 勾选采购项
-> 查看协议
-> 退出登录
```
