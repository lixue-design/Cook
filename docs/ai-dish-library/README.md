# AI 菜品图库边界

本文定义当前仓库中 AI 菜品图片库相关能力在 MVP 阶段的边界。结论先行：**AI 菜品图库不是 MVP 必需闭环**，不得把 AI 生成菜谱、图片识别菜谱、文字生成菜谱、运营后台或生产模型调用混入 MVP 主线。

## 1. MVP 定位

MVP 主链路仍是：

```text
微信登录 -> 手动新建菜谱 -> 管理菜谱库 -> 生成/编辑周计划 -> 同步周菜篮 -> 勾选采购
```

AI 图片库在 MVP 中最多作为封面辅助扩展点：用户输入菜名后，系统可以尝试从已有本地图库匹配封面。匹配失败、服务不可用或图片读取失败时，必须允许用户继续无图保存或手动选择图片，不能阻塞菜谱创建和编辑。

## 2. 当前代码状态

| 范围 | 文件或目录 | 当前状态 | MVP 处理 |
| --- | --- | --- | --- |
| 图片搜索 | `services/dish-image-api.js` | 小程序调用 `/api/dish-images/search`，把返回路径转为绝对图片 URL。 | 可保留为菜名封面匹配体验。失败时降级为无图或手动图片。 |
| 图片搜索服务 | `server/src/app.ts`、`server/src/dish-image-library.ts` | 提供 `GET /api/dish-images/search?q=&limit=` 和 `GET /api/dish-images/{assetId}`；按关键词查询 `dish_asset_keywords`、读取本地存储图片。 | 可作为非核心辅助服务；不能承诺 AI 生成菜谱。 |
| 方舟生图兜底 | `server/src/ark-dish-image-generator.ts`、`server/src/server.ts`、`server/src/config.ts` | 仅当服务端配置 `ARK_API_KEY` 和 `ARK_IMAGE_MODEL` 时启用；负责生成缺失菜品图片并写入图库表。 | 非 MVP 主线能力。默认不配置生产密钥，不在页面承诺可用。 |
| 数据库结构 | `database/migrations/0001_ai_dish_library.*.sql`、`database/migrations/0006_local_dish_image_search.*.sql`、`database/tests/0001_ai_dish_library.test.sql` | 已有菜品、别名、图片资产、关键词、生成任务等结构和验证 SQL。 | 保留历史结构，不扩展运营后台或生成流程。 |
| 测试 | `server/test/dish-image-library.test.ts`、`server/test/ark-dish-image-generator.test.ts` | 覆盖图片搜索、读取和方舟兜底生成纯逻辑。 | 后续只有修改相关代码时才需要同步更新。 |
| 图片资产 | `storage/dish-images/` | 包含本地示例图片和已生成图片文件。 | 可用于本地开发或封面匹配演示；不代表生产素材运营能力。 |

## 3. MVP 允许能力

- 输入菜名后尝试匹配已有图库封面。
- 图片搜索失败时展示轻量提示，并允许继续保存。
- 手动选择封面图或步骤图。
- 保留服务端环境变量读取能力，用于后续专项验证。

## 4. MVP 禁止能力

- AI 链接生成菜谱，包括外链解析和自动抽取字段。
- AI 图片识别生成菜谱，包括拍照、相册识别、OCR 或视觉模型抽取菜谱。
- 文字生成菜谱或文本自动拆分成完整菜谱。
- AI 自动生成周菜单。
- AI 生图作为 MVP 必需功能或用户可依赖功能。
- 图库运营后台、素材审核、同义词运营、全局素材再生成。
- 在业务代码、配置样例、文档或测试数据中提交真实模型密钥、AppSecret、token 或生产地址。

新增以上能力前，必须先更新 MVP 范围或新增专项 spec 和任务卡。

## 5. 页面入口策略

| 入口 | 当前策略 | 验收要求 |
| --- | --- | --- |
| 菜谱列表新增弹窗的链接导入 | 标记为即将上线；点击或提交时提示暂不支持，建议手动填写。 | 不应让用户以为 MVP 已支持链接导入。 |
| 菜谱列表新增弹窗的图片识别 | 标记为即将上线；点击时提示暂不支持。 | 不调用图片识别或模型服务。 |
| 菜谱列表新增弹窗的文本识别 | 标记为即将上线；点击时提示暂不支持。 | 不承诺文本自动生成菜谱。 |
| 菜谱创建页封面匹配 | 保留“匹配菜品图片”语义；错误提示强调可继续无图保存。 | 匹配失败不阻塞保存。 |
| 菜谱创建页 AI 绘图 | 标记为即将上线；点击时提示 MVP 暂不支持。 | 不调用生图接口。 |
| 计划新增方式弹窗 AI 菜单 | 标记为即将上线；点击时提示暂未上线。 | MVP 周计划生成走规则引擎，不接 AI。 |

## 6. 密钥和配置约束

- 模型密钥只允许通过服务端环境变量注入，例如 `ARK_API_KEY`。
- 默认开发和 MVP 提审环境不要求配置 `ARK_API_KEY` 或 `ARK_IMAGE_MODEL`。
- `.env.example`、README、任务卡和测试只能出现变量名，不能出现真实值。
- 小程序端不得保存或透传模型密钥。

## 7. 后续专项触发条件

以下任一需求出现时，必须新建专项 spec 和任务卡：

- 产品确认 AI 链接导入、图片识别、文字生成进入版本范围。
- 需要正式启用方舟兜底生成并接入生产密钥。
- 需要运营后台管理菜品图、别名、审核和再生成。
- 需要把图库匹配变成保存菜谱的强依赖。

专项任务必须补充 API 契约、错误态、鉴权、内容安全、成本控制、人工审核和回滚方案。
