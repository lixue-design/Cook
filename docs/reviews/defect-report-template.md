## 严重级别参考

| 级别 | 标准 |
| --- | --- |
| P0 | 主路径不可用、数据错乱或丢失、越权、泄露密钥或真实用户隐私、提审阻断。 |
| P1 | MVP 核心能力失败，存在明确绕行但影响验收，例如菜谱保存失败、计划快照错误、菜篮合并错误。 |
| P2 | 非主路径失败、错误态缺失、视觉或交互明显回归，但不阻断核心闭环。 |
| P3 | 文案、记录、轻微样式或低频兼容问题。 |
